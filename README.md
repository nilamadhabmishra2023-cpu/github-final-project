# Simple Interest Calculator

## Project Name
Simple Interest Calculator

## Description
This project contains a Bash script to calculate simple interest based on the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the `simple-interest.sh` script and enter the principal amount, rate of interest, and time period when prompted.
